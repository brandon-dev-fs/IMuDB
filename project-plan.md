# IMuDB

Internet Music Database is a online directory of information on musicians and albums that lets you discover details about what you're listening to. You can scroll through artist or albums, give your ratings, create playlist, create and share blog post

## Technology

Built on React SPA (Single Page Application) with ASP.NET Rest API.

## Pages/Components

### Header

Header website Icon
Navigation to the various pages

### Landing Page

Opening Page of the site
Explains what the site is
If a user is signed in shows them playlist, blog post, etc.

### Artist Page

A list of available artist to look up
Click on an artist to go to their details page
Filter the list on genre or band/single
Search by name
Button to Add new artist

### Artist Details Page

List the members of the band
Band/Artist Description
Years active
Album discography of the band/artist
Button to edit the artist

### Albums Page

A grid of albums
Each album card in the grid has the album cover and name in the body with a link to the album details page
Filter by genre or artist
Search by name
Button to Add new albumn

### Album Details Page

Album name and year
Cover Art
Band/Artist
Track List
Button to edit the Album

#### Song Modal

Shows the song details
Track Length
Lyrics
If a user their song rating
Writing or instrument credits
Edit song button

### Playlist Page

List of different user playlist
List of shared or suggested playlist
